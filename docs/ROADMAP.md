# MoonLan — дорожная карта

Полный целевой набор функций (аналог LanTopoLog) и версии, в которых они появятся.

- [x] **v0.1** SNMP-опрос коммутаторов, BRIDGE-MIB, автоматическая топология, двухпанельный веб-интерфейс, поиск, демо-режим
- [ ] **v0.2** Ручное редактирование схемы, сохранение раскладки, настраиваемые контекстные меню устройств _(перенесён — сознательно пропущен, будет реализован в одной из следующих версий)_
- [x] **v0.3** Непрерывный Ping-мониторинг, дата/время последнего ответа, автообнаружение новых устройств, журнал новых MAC-адресов, определение IP и имён хостов (ARP/DNS)
- [x] **v0.4** Корректный алгоритм прямых связей (без ложных связей в звезде), LACP-агрегаты (IEEE8023-LAG-MIB), VLAN на портах (PVID и имена), обнаружение неуправляемых коммутаторов _(счётчики ifInErrors/ifOutErrors/ifInDiscards/ifOutDiscards перенесены в v0.5)_
- [x] **v0.5** Тревоги: email, Telegram, Syslog; пороговые значения трафика; мониторинг трафика до порта коммутатора; счётчики ошибок портов (ifInErrors/ifOutErrors/ifInDiscards/ifOutDiscards)
- [x] **v0.5.1** Наблюдаемые хосты (host_down только по отмеченным); тревоги port_hosts_down и lag_degraded; честная скорость деградировавшего LAG; один SnmpEngine на процесс (утечка fd/памяти); фильтр аномальных скоростей счётчиков; пример systemd-юнита
- [x] **v0.5.2** Стабильные субъекты LAG-тревог (по составу членов); санитар зависших тревог; ручное снятие тревоги; лог ресурсов на INFO и в /api/status; подавление флаппинга (FLAPPING-уведомления)
- [x] **v0.5.3** Уникальность IP хостов (ложные port_hosts_down); grace-период для «тихих» хостов (stale на карте); раздел «Вне карты» для устройств из ARP вне портов; отчёт `diag --hosts` о полноте инвентаря; читаемая панель тревог
- [x] **v0.5.4** Разделение ошибок и отбрасываний (port_errors vs port_discards); относительный критерий ошибок по счётчикам пакетов; псевдо-коммутаторы с учётом известных из БД хостов; `diag --port --watch`; подсветка и сортировка в панели портов
- [x] **v0.5.5** Группировка офлайн-устройств в узлы «Офлайн · N»; подсветка подписи выделенного узла
- [x] **v0.5.6** Возврат непрерывной физики и ручная кнопка «Заморозить раскладку»; офлайн-группы всегда показывают свои устройства; аудит конфигурации `diag --config` и сводка в логе при старте
- [ ] **v0.6** Контроль Spanning Tree (STP) и уведомления об изменениях топологии
- [ ] **v0.7** Экспорт схемы в PDF и Draw.io (diagrams.net); импорт дополнительных сведений по MAC-адресам
- [ ] **v0.7** Контекстное меню узла с диагностическими действиями (ping, traceroute, ссылки на SSH/RDP/веб-интерфейс устройства, пользовательские команды из config) — аналог контекстного меню LanTopoLog
- [ ] **v0.8** Инвентаризация компьютеров через WMI/WinRM
