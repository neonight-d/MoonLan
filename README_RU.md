# 🌙 MoonLan

**MoonLan** — веб-сервис для Linux, который сам строит физическую топологию локальной сети по данным коммутаторов, собранным по SNMP, и показывает её в браузере вживую. Открытая альтернатива LanTopoLog.

> **Принцип:** показывать то, что сеть действительно сказала, и явно помечать выведенное, устаревшее, приблизительное и неизвестное.

![Карта сети MoonLan](docs/img/map.png)

Подробная документация — в каталоге `docs/`, на английском.

## 🚀 Быстрый старт

Linux, Python 3.11+, коммутаторы с SNMP v2c (community только на чтение).

### Установка

~~~bash
git clone https://github.com/neonight-d/MoonLan.git
cd MoonLan

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
~~~

### Настройка

~~~bash
cp config.example.yaml config.yaml
# укажите адреса коммутаторов и SNMP community
~~~

`config.example.yaml` прокомментирован по-русски и по-английски. Все
ключи с умолчаниями: **[docs/CONFIGURATION.md](docs/CONFIGURATION.md)**
(на английском).

### Запуск

~~~bash
python run.py
~~~

Откройте `http://<сервер>:8080/`.

Для безопасного первого знакомства — виртуальная сеть:

~~~bash
MOONLAN_DEMO=1 python run.py
~~~

Запуск как сервис systemd, демо, второй экземпляр рядом с работающим:
**[docs/OPERATIONS.md](docs/OPERATIONS.md)** (на английском).

## 🔐 Пользователи и вход

Пока нет первого администратора, карта открыта всем, кто до неё
дотянется, — как до v0.7.4, — и шапка говорит об этом. Первый
администратор создаётся на сервере, а не в браузере:

~~~bash
python -m moonlan.users add <имя> --role admin
~~~

Вход включается сразу, без перезапуска. Три роли: **наблюдатель**
смотрит; **пользователь** ещё и пингует, опрашивает сеть, закрепляет
узлы и снимает тревоги; **администратор** ещё и сбрасывает раскладку и
управляет учётными записями, и обязан использовать TOTP. По обычному
HTTP пароль и сессия идут по сети открытым текстом — HTTPS будет в
v0.7.6.

Роли, TOTP, восстановление доступа, что оставляет открытым HTTP:
**[docs/SIGN-IN.md](docs/SIGN-IN.md)** (на английском).

## 🧪 Тесты

MoonLan использует стандартный `unittest`:

~~~bash
python -m unittest discover -s tests -v
~~~

CI прогоняет тесты на Python 3.11 и 3.12 при каждом пуше в **main** и в пулл-реквестах.

Исправляя топологию, опрос, хранение или поведение конкретного вендора, добавьте регрессионный тест на сам сбой. Тесты нарочно защищают тонкие правила: устаревшие показания, проверку FDB, вывод топологии, хранение раскладки, безопасность команд, права и частичные отказы SNMP.

## 🏗️ Архитектура

~~~text
Коммутаторы и маршрутизаторы (SNMP)
          │
          ▼
   SnmpCollector + probes
          │
          ▼
 ┌─────────────────────────┐
 │ вывод топологии         │
 │ LLDP / FDB / LACP       │
 │ STP / VLAN / ARP        │
 └────────────┬────────────┘
              │
              ▼
        TopologyState
          │       │
          ▼       ▼
       SQLite   FastAPI ◄── вход, таблица прав
          │       │
          └───┬───┘
              ▼
        Веб-интерфейс
~~~

Сбор, вывод топологии, хранение, API и интерфейс нарочно разделены. Медленный или отвечающий частично коммутатор не должен приводить к исчезновению остальной сети.

Поток данных, таблица прав и границы оптимизаций: **[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)** (на английском).

## 🔌 REST API

| Метод | Маршрут | Назначение | Роль |
|---|---|---|---|
| GET | **/api/health** | Жив ли сервис: статус и версия, больше ничего | без входа |
| POST | **/api/auth/login**, **/api/auth/totp** | Вход: пароль, затем код | без входа |
| GET | **/api/status** | Состояние опроса, сервиса и ресурсов | наблюдатель |
| GET | **/api/topology** | Текущая топология и состояние устройств | наблюдатель |
| GET | **/api/switch/{ip}/ports** | Порты: статус, скорости, ошибки, LLDP, LAG, петли | наблюдатель |
| GET | **/api/stp** | STP и вердикт по сети | наблюдатель |
| GET | **/api/alarms** | Активные и снятые тревоги | наблюдатель |
| POST | **/api/alarms/{id}/clear** | Снять активную тревогу | пользователь |
| GET | **/api/journal** | Журнал событий, с тем, кто что сделал | наблюдатель |
| GET | **/api/search?q=...** | Поиск устройства | наблюдатель |
| GET/PATCH/DELETE | **/api/layout** | Общая раскладка | наблюдатель / пользователь / администратор |
| GET | **/api/node-menu?id=...** | Что предлагает меню узла | наблюдатель |
| POST | **/api/actions** | Запустить ping или traceroute | пользователь |
| POST | **/api/scan** | Опросить сеть сейчас | пользователь |
| … | **/api/users** | Учётные записи | администратор |

Роль действует, когда вход включён. Все маршруты, их роли и ответы:
**[docs/API.md](docs/API.md)** (на английском).

## 🛡️ Безопасность

MoonLan рассчитан на доверенную сеть, которую вы обслуживаете сами.

- SNMP community v2c — это пароль, храните его как пароль.
- Не выставляйте сервис напрямую в недоверенную сеть.
- Создайте администратора, чтобы закрыть карту входом; до тех пор она открыта всем, кто до неё дотянется.
- По обычному HTTP пароли и cookie сессий идут по сети открытым текстом (HTTPS — v0.7.6).
- Действия по запросу принимают идентификаторы узлов MoonLan, а не произвольные адреса, и выполняются без оболочки.
- Свои ссылки меню проверяются по списку схем, подставляемые значения URL-кодируются.
- Прочитайте **[SECURITY.md](SECURITY.md)** (на английском), прежде чем открывать MoonLan за пределами лаборатории или доверенной сети.

## 🤝 Как внести вклад

Лучше небольшие точные изменения, чем широкие переписывания.

1. Воспроизведите проблему.
2. Добавьте регрессионный тест.
3. Сохраняйте публичные API и имена классов, если несовместимость не задумана.
4. Прогоните все тесты.
5. Обновите документацию, если меняется поведение; видимый пользователю эффект опишите в pull request.
6. Версию и CHANGELOG не трогайте — их пишут при выпуске релиза.

Подробнее — **[CONTRIBUTING.md](CONTRIBUTING.md)** (на английском).

### Зачем MoonLan

Карта сети полезна, только если отличает **наблюдение от вывода**. MoonLan нарочно держит это различие на виду: измеренный кабель, связь, выведенная из FDB, приблизительное размещение за магистралью и устаревшее показание никогда не должны выглядеть одинаково.
